# Лабораторная работа №2: Natural Language Processing (NLP)
## 1. Описание задачи

### Инженерная задача
1. Установка и настройка сервера **Ollama**.
2. Загрузка легковесной языковой модели **Qwen2.5:0.5B**.
3. Реализация Python-скрипта для взаимодействия с моделью по протоколу HTTP (библиотека `requests`).
4. Проведение инференса (тестирования) на 10 произвольных запросах.
5. Формирование отчета инференса.

---

## 2. Стек технологий
*   **Среда выполнения:** Google Colab / Linux.
*   **Инструментарий:** Ollama.
*   **Модель:** Qwen2.5:0.5B (0.5 миллиарда параметров).
*   **Библиотеки:** `requests` (для связи с API), `pandas` (для формирования отчетов).

---
